# DNA Sequence Analyzer

This is my Python project for basic DNA sequence analysis.

The program takes a DNA sequence and gives some simple information about it.

## What the program does

- takes DNA input
- checks if the input is valid
- counts A, T, G and C
- finds the length
- calculates GC Content

## Files

main.py - starts the program

input_file.py - takes input from the user

validation.py - checks the DNA characters

analysis.py - does the counting and GC calculation

output.py - prints the final answer

test_project.py - tests some parts of the program

## How to run

Open the folder in VS Code or Command Prompt.

Run:

python main.py

Then choose 1 and enter a DNA sequence.

Example:

ATGCCGTA

To run the tests:

python test_project.py
