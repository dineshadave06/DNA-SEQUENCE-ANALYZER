# Project Statement

## Project

DNA Sequence Analyzer

## Problem

A DNA sequence contains four main characters: A, T, G and C. If the sequence is long, counting the characters manually takes time.

I made this program to do the basic counting automatically.

## Scope

The project only does basic sequence analysis. It checks the input, counts the four bases, finds the length and calculates GC Content.

It is not meant for advanced DNA or medical analysis.

## Users

This can be used by students who are learning Python or anyone who wants basic information about a DNA sequence.

## Main features

1. DNA input
2. Input validation
3. A/T/G/C count
4. Sequence length
5. GC Content
6. Simple output
7. Basic testing
